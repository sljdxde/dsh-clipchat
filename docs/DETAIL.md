# 滑词对话（dsh-clipchat）

选中 assistant 回复里的一段文字，浮层出现「引用文本 / 问这段」；点「问这段」在原地展开卡片，提问、连续追问、查看 token，并把重点高亮留在原文上。

## 功能

- 选区菜单保留宿主「引用文本」，并列增加「问这段」。
- 卡片：流式回答、连续追问、模型选择（默认跟随主会话）、输入/输出 token、停止生成。
- 高亮：显式提交后按会话持久化；点击高亮回看当时的问答。
- 留痕：显式保存问答，卡片内列表可查看、删除、打「当前选段」标签。
- 带回主线：引用选段 + 不超过 200 字的问答摘要插入主输入框，不自动发送。
- 存储：`DSH_HOME/clipchat/<sessionId>.json`；7 天无访问清理；归档保留；永久删除会话后由孤儿清理删除。

## 边界

- 只处理 assistant 正文；用户消息只保留原生引用。
- 不写主会话、不建隐藏会话、不调用工具。
- 只读会话或子会话不出现滑词入口；若宿主没有可写的引用 surface，会显示一条不可用提示。
- 与 dsh-sidenote 同时安装时，若它隐藏原生引用，本插件的「问这段」也随引用 surface 一起隐藏；这是刻意的共存行为。

## 已知限制

- 高亮 overlay 依赖聊天列的 `[data-chat-flow]` 结构；上游改版可能需要跟着调整。
- 多段跨块选区的重锚只在单块、单 span 时做前缀回退；多 span 依赖精确偏移。
- 卡片打开期间若聊天区被虚拟化替换到选区节点，宿主可能关闭浮窗；M1 接受该风险。
